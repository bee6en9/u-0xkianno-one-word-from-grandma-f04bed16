The single word a grandma would text about AI: **Contraption**.

Her generation's word for a machine, applied to the newest machine of
all — warm, a little baffled, and funny with no caption needed.

## How it works

`main.ts` (Node, no dependencies, no network) writes exactly one word to
`/output/entry.txt`:

```text
Contraption
```

The program guards the gate: it throws unless the entry is a single word
of 1–30 characters with no whitespace.
